{% comment %} Extras section (Cot & High Chair, Airport Transfers, Late Checkout, Welcome Pack & Special Requests) shared by details.html, balance_details.html, and manage_extras.html. Expects the usual _extras_context()/_transfer_context() variables in the parent context, plus a `due_phrase` string for the one substring that differs per caller ("the amount due now" / "your balance payment" / "any online payment"). `transfers_hoisted` (2026-09-15): set only by the merged multi-property Extras page, which renders this whole partial once PER APARTMENT and so must not repeat the two things that belong to the stay as a whole - the Airport Transfers section (one transfer for the party, per Thomas) and the cot/high-chair pricing config (identical for every leg, and a duplicated json_script id would be invalid HTML). That page renders both once itself, outside the per-apartment loop. Every other caller leaves the flag unset and renders exactly as before. `extras_property`: when set (merged page only), each section heading gains a "Heading - Property" suffix, per Thomas's em-dash convention for distinguishing apartments. Airport Transfers deliberately never gets one - it's hoisted out and shared. `leg_id_suffix`: appended to the one id/label-for pair in here, so the association still works when this renders more than once on a page. Empty everywhere else. `omit_transfers_cash_note`: set by callers (manage_extras.html, balance_details.html) whose page-level note already says extras are paid in cash at check-in, so the Airport Transfers section's own copy of that line isn't repeated right underneath it. details.html has no such page-level note, so it leaves this unset and keeps the line. {% endcomment %}
